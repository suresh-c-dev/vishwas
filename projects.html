Smart Biometric Seat Identification System
2024 — 2025

Built a fingerprint-based seat detection system using Arduino UNO and R307 optical sensor. LED indicators are mapped to each seat via Arduino EEPROM — no external database needed. Enrollment and verification phases implemented with the Adafruit_Fingerprint library.

Key Highlights
  • ▸Fingerprint enrollment & verification phases
  • ▸EEPROM-based storage — no external database
  • ▸LED indicators per seat for real-time status
